# Globalisation in India 🌏

A simple educational webpage explaining the concept of **globalisation** and its impact on **India’s economy, culture, technology, and society**.  
This project is part of my Class 10 academic work.

---

## 📖 About the Project
This website covers:
- Meaning of globalisation  
- Positive impacts on India  
- Negative impacts on India  
- Role of MNCs  
- Government policies  
- Real-life examples  

The goal is to present the topic in a clear, student-friendly format.
